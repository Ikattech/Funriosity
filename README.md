# Project Oasis

Uma engine quântica, isto é, um motor de simulação física cujo núcleo modela os fenômenos da física quântica e, a partir deles, os fenômenos da física real. O motor é destinado à criação de jogos e
softwares, e permite que qualquer pessoa desenvolva seus projetos com base na física real ou em uma física alterada conforme sua escolha.

O sistema é concebido como uma ferramenta única e unificada: um mesmo motor serve tanto à simulação fiel de leis físicas quanto à definição de leis novas, de modo que a diferença entre um jogo baseado no
mundo real e um jogo com regras próprias seja apenas uma questão de parametrização.

Objetivos
- [ ] Núcleo de simulação baseado em mecânica quântica
- [ ] Modelagem de sistemas clássicos a partir do núcleo quântico
- [ ] Simulação numérica de corpos e campos sob gravidade
- [ ] Parametrização das leis físicas pelo usuário
- [ ] Geração procedural de estruturas, relevos e ambientes
- [ ] Simulação de sistemas de N corpos
- [ ] Interface de programação para criação de jogos e softwares
- [ ] Documentação e exemplos de uso para desenvolvedores
Nota final

Projeto de longo prazo. Os objetivos não seguem ordem fixa e podem ser executados em paralelo, conforme a evolução de cada componente.
